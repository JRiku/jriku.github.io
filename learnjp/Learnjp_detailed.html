Detailed Timeline to Conversational Fluency

1. Learn Hiragana and Katakana

  • Understand their role: Read the Wikipedia article about Japanese writing systems.
  • Study methods:
    • Use the Tofugu guide (especially if you like mnemonics).
    • Use charts like the NHK World Japan chart for direct lookup.
    • Watch YouTube videos like those from Japanese Pod 101 and follow pronunciation.
    • If you prefer learning Hiragana and Katakana as pairs, read the Toki and Andy blog.
    • Practice stroke order to aid future reading and writing.

2. Learn Basics of Kanji and Grammar

  • Kanji fundamentals:

    • Learn stroke order and radicals (components of Kanji).
    • Understand that Kanji are composed of parts, making them easier to recall (e.g., 雑 = 九 + 木 + 隹).

  • Dictionaries:

    • Use Jisho.org and jpdb.io for looking up words.

  • Install Anki:

    • Anki is a spaced-repetition flashcard app.
    • Download and install the Kaishi 1.5k deck (1,500 starter words).
    • Set new cards per day to 5.
    • Add the Jikaku deck for later progression.

  • Study grammar:

    • Read Tae Kim’s Guide to Japanese Grammar.
      • Pages 13–27: Writing system basics.
      • Pages 29–81: Core grammar and sentence construction.

3. Setup Immersion Tools

  • Yomitan Extension:
    • Browser dictionary popup with Anki integration.
    • Use it to auto-create Anki cards for unknown words.
    • Prioritize common words (CC100 < 30,000).
    • Configure Yomitan via TheMoeWay guide.

4. Start Beginner Immersion

  • Watch beginner-friendly YouTubers:

    • Nihongo no Mori
    • Meshclass
    • That Japanese Man Yuta
    • NihongoDekita with Sayaka
    • Toppogi Kanji Lesson
    • Moshimoshi Yuusuke
    • Onomappu

  • Use Graded Readers to practice simple texts.

  • Set a Calendar Reminder:

    • Schedule a check-in 1 year from today to evaluate your progress.

  • Progress Evaluation:

    • Watch your first beginner Japanese YouTube video.
    • If you understand >70%, move on to native content.
    • Avoid beginner content and foreigner-made Japanese videos to prevent bad habits.

5. Start Output (~6 months in)

  • Start typing in Japanese:

    • Use Twitch: Find low-viewer Japanese streamers in categories you like.
      • This gives time to formulate responses without pressure.

  • Move to speaking practice:

    • Use platforms like:
      • Discord (e.g., ENJP Games Server, English-Japanese Exchange)
      • Italki, HelloTalk

  • Expect to be overwhelmed, but focus on:

    • Picking out essential words from decorative ones.
    • Using Jisho or JPDB to look things up quickly.
    • Building stamina for full-focus conversations.

6. Advance to Native Conversation

  • Join higher-level Japanese servers (e.g., Mayofuwa, Yamisa) only when you're ready.
    • Miscommunication can cause tension, so choose your timing wisely.

7. Finish Jikaku Deck (~2 years in) and Decide: Monolingual Switch

  • Debate in the community:

    • English-side: Faster reviews, more time for immersion.
    • Monolingual-side: Learn like a native; better nuance and depth.

  • Assuming monolingual switch:

    • Read TheMoeWay guide again for setup.
    • Download monolingual dictionaries from the dictionary folder.
    • Test and compare to find a dictionary you can actually understand.
    • Set your favorite as default in Anki/Yomitan.

8. Start Mining

  • What is mining?

    • Finding new words from native content using Yomitan.
    • Add them to your own Anki deck for continuous growth.

  • Tips:

    • Always have 1–2 weeks of extra cards ready for busy times.
    • Mine what is personally interesting or necessary for you.

9. Intermediate Plateau

  • Signs:

    • Understand 70–80% of most things.
    • Motivation dips as each new word brings less visible progress.

  • What to do:

    • Stay consistent with 10 cards/day.
    • Reflect on which methods work.
      • If you have too many leeches, try:
        • Adding pictures
        • Making physical flashcards
        • Using Jisho.org screenshots for tough words

10. Further Literacy and Handwriting

  • Expand Kanji knowledge:

    • Use Kanji Kentei Anki decks (Levels 10 to 1).
    • Stopping after Level 2 puts you at Japanese high schooler level.

  • Study handwriting:

    • Use handwriting decks to boost active recall.
    • Pull words from passive to active vocabulary.

  • Check your grammar:

    • If you haven’t done Bunpro or Tae Kim thoroughly, catch up now.
